Тази таблица е на проекта, а не на ASD. Тя дава прост заместител на думите, които AI текстът и канцеларският стил използват твърде често. Ако думата не носи факт, изтрийте я, а не я заменяйте.

## Канцеларщина

Българският технически текст има собствен „слоп“: канцеларския стил. Той крие глагола в съществително и удължава изречението.

| Канцеларщина | Напишете вместо това |
|---|---|
| осъществявам, извършвам, реализирам (действие) | правя, или глаголът на действието: „извършете проверка“ → „уверете се, че“ |
| предприемам действия по | (глаголът на действието) |
| посредством, чрез използването на | с, чрез |
| във връзка с, по повод на | за |
| с оглед на | заради, за |
| касае, засяга | е за |
| следва да | трябва (изискване) / (изтрийте) |
| горепосочен, гореописан, гореспоменат, долупосочен | този, или назовете целта |
| в рамките на | в, по време на |
| по линия на | в, за |
| с изключение на | освен |
| на база на, въз основа на | по, според |
| вследствие на | заради, поради |
| е налице | има |
| да бъде | да е, или деятелен залог |
| имплементирам | добавям, пиша, правя |
| валидирам, верифицирам, удостоверявам | уверете се, че |
