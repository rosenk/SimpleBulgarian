# Строг режим: контролираният речник

Прочетете този файл, когато потребителят поиска „строг режим“, „контролиран език“, STE или подготовка за машинен превод. Строгият режим добавя правилата на речника към документа. Той не променя отговора към потребителя, който остава в Обикновен режим.

ASD-STE100 има официален речник само за английски. За български официален контролиран речник няма. Този файл дава собствен речник на проекта: по един глагол за всяко често софтуерно действие и списък с отхвърлени думи. Кажете на потребителя веднъж в разговора, с едно изречение, че това не е стандарт, а правило на този skill.

## Правилата, които съществуват само с речник

| Правило | Инструкция |
|---|---|
| 1.1 | Използвайте само одобрените думи, техническите съществителни и техническите глаголи. |
| 1.2 | Използвайте одобрената дума само като нейната част на речта. |
| 1.3 | Използвайте одобрената дума само в одобреното значение. |
| 1.4 | Използвайте само одобрените форми на глаголите. БГ: за инструкция винаги свършен вид в повелително наклонение („инсталирайте“, а не „инсталирвайте“). |
| 1.6 | Използвайте неодобрена дума само когато тя е технически термин или част от него. |
| 3.1 | Използвайте само глаголните форми, които речникът дава. |
| 9.2 | Използвайте всяка одобрена дума правилно: одобрено значение, одобрена част на речта. |
| GR-5 | БГ: пазете се от фалшиви приятели. „Актуален“ не е „actual“ (действителен). „Евентуално“ не е „eventually“ (накрая). „Адекватен“ не е „adequate“ (достатъчен). „Ефективен“ и „ефикасен“ не са едно и също. |
| GR-8 | Без притежателни конструкции, които могат да се разберат двояко. Ако не сте сигурни, напишете „файлът на потребителя“. |

## Отхвърлени думи и заместители

<!-- bg-lint off -->

| Написали сте | Строгият режим пише |
|---|---|
| обаче | но |
| следователно, ето защо | в резултат |
| тъй като, понеже | защото |
| сега (в процедура) | изтрийте го: „сега стартирайте услугата“ → „стартирайте услугата“ |
| необходимо е да, нужно е да | повелително наклонение в процедурата („инсталирайте“), „трябва“ в описанието |
| извършете, осъществете, реализирайте | направете, или глаголът на действието |
| вмъкнете | поставете (но SQL `INSERT` остава, защото е цитиран текст) |
| достигнете | стигнете до |
| избягвайте | предотвратете |
| повторете | направете отново |
| допустим, приемлив | позволен. По-добре дайте границата: „закъснение под 200 ms“ |
| пълен (за процес) | завършен |
| горепосоченият, долупосоченият, гореописаният | назовете целта или поставете препратката след нея: „примерът, който следва“ |
| всякакви, какъвто и да е | изтрийте или преустройте: „ако имате някакви въпроси“ → „ако имате въпроси“ |

## Строга самопроверка

Добавете тези три стъпки към самопроверката в SKILL.md:

1. Потърсете в текста всеки глагол от колоната „Не пишете“ и всяка дума от таблицата с отхвърлени думи. Заменете всяко попадение с одобрената дума.
2. Потърсете описателните изрази в текста („извършете инсталиране“, „направете проверка“). Заменете всеки с еднословния глагол (правило 9.3).
3. Потърсете английски думи с българско окончание („сетнете“, „рънете“). Заменете всяка с одобрения глагол или с английския термин в обратни кавички.
